# Alpha 7 Frontend and Backend Contract Consolidation

Alpha 7 registers canonical production HTTP operations in `ALPHA7_API_CONTRACT_REGISTRY.json`, validates analyzer request and response payloads at the frontend boundary, detects route and schema drift in qualification, and reports the registry in Debug Report v2. `readerSpans` remains the sole linguistic Reader truth. The backend route set and semantics are unchanged. Teaching, correction, dictionary, startup, EPUB, prefetch, known-word, enrichment, and Yomitan boundaries remain frozen.
