# Alpha 9 Legacy and Unwanted Code Retirement

Alpha 9 performs bounded, evidence-backed retirement. The unused `LEGACY_CACHE_KEY` symbol is removed while the literal cleanup operation remains so existing installations can still delete the retired cache record. No retired cache is read or restored as known-word authority.

The consumer audit retains Reader interaction compatibility, Phase 5 mining exports, Reader-progress migrations, version 3 known-word records, authoritative EPUB fallback, the Phase 3 prefetch wrapper, the dictionary-form mechanical alias, and tokenizer retirement qualification. Each retained item has an explicit blocker in `ALPHA9_RETIREMENT_EVIDENCE.json`.

JP Analyzer production code and all Alpha 1-8 authority boundaries remain unchanged.
