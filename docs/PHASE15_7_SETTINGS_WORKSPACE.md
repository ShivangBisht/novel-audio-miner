# Phase 15.7 Settings and Administration Workspace

## Result

The former nested Tools disclosures are replaced by one responsive application workspace with Reading, Integrations, Dictionaries, Teaching administration, and Diagnostics sections. The Reader remains the owner of current settings and callbacks; the workspace is a presentation component.

## Preserved contracts

Reading progress, AnkiConnect requests, known-word cache ownership, dictionary transactions, Teaching administration clients, Debug Report v2, API contract diagnostics, persistence diagnostics, status domains, startup supervision, JP Analyzer, and the VBScript launcher are unchanged.

## Accessibility and privacy

The workspace is a labelled modal dialog with section navigation, visible current-section state, Escape close behavior, responsive full-screen presentation, touch-sized controls, and reduced-motion handling. The Nadeshiko session token is masked and remains in existing local browser storage; it is not added to diagnostic exports.
