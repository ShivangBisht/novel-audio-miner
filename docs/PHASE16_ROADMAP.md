# Phase 16 Preserved Roadmap

## Status

Phase 16 is preserved now so Alpha and resumed Phase 15 cannot erase its
purpose. Alpha stabilizes current authority and removes drift. Phase 15 then
completes the visual overhaul. Phase 16 builds the next deliberate product and
operational capabilities on that clean foundation.

## Phase 16.1: Enrichment workflow refinement

Improve the stabilized newest-Kiku-note enrichment experience, receipts,
retryability, provider diagnostics, field mapping, and partial-failure recovery
without linking Yomitan to the application.

## Phase 16.2: Enrichment history and observability

Add local, privacy-conscious enrichment history, target note ID, provider used,
media results, timings, failures, and retry status. Do not store dictionary
meaning or personal Anki content unnecessarily.

## Phase 16.3: Book-aware enrichment profiles

Support reusable per-book or per-series enrichment profiles for note type, field
mapping, audio provider preference, image policy, sentence formatting, and
metadata while retaining one canonical enrichment contract.

## Phase 16.4: Advanced Reader interaction

Build optional keyboard span traversal, command palette actions, accessible
selection navigation, and high-volume reading workflows on the canonical Alpha
interaction identity.

## Phase 16.5: Performance and bundle architecture

Introduce measured code splitting, lazy administration workspaces, asset and
cache profiling, startup performance budgets, and Reader rendering budgets.

## Phase 16.6: Diagnostics and supportability

Unify cross-project diagnostics, exportable sanitized support bundles, contract
identities, cache health, persistence health, and enrichment receipts.

## Phase 16.7: Data portability and recovery

Provide documented export, backup, restore, and verification for user-owned
settings, manual-known state, Reader progress, corrections, Teaching evidence,
and relevant backend stores.

## Phase 16.8: Security and privacy hardening

Review tokens, local configuration, debug exports, CORS, localhost boundaries,
media handling, file uploads, dependency risk, and sensitive-field redaction.

## Phase 16.9: Extended qualification

Add long-running Reader, dictionary, correction, Teaching, startup, enrichment,
and migration qualification across supported Windows configurations.

## Phase 16.10: Product closeout

Update both snapshots, publish architecture and recovery documentation, remove
completed migration scaffolding, merge, and create matching Phase 16 tags.
